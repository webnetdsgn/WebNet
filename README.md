# WEBNET — портфолио арт-директора

Готовый сайт без сборки и без установки. Обычные файлы: HTML, CSS, JS.

## Что внутри

```
index.html            главная страница портфолио (открывать её)
works/
  britva.html         сайт: барбершоп с онлайн-записью и сертификатом (концепт)
  zerno.html          сайт приложения: кофейня, внутри рабочий прототип (концепт)
  ritm.html           сайт приложения: фитнес, внутри рабочий прототип (концепт)
assets/
  metrika.js          счётчик Яндекс Метрики (нужно вписать один номер)
  want.js             кнопка «Хочу такой же» на страницах работ
  covers/             картинки для карточек работ
  vendor/             библиотеки анимации (лежат локально, интернет не нужен)
```

## Как запустить у себя

1. Распакуйте архив в любую папку.
2. Дважды щёлкните по `index.html`. Откроется в браузере.

Шрифты подгружаются из Google Fonts. Без интернета сайт откроется, но шрифты будут системные.

## Как выложить в интернет (бесплатно)

**Netlify Drop**
1. Откройте https://app.netlify.com/drop
2. Перетащите папку с файлами (где лежит index.html) в окно.
3. Получите ссылку вида `что-то.netlify.app`.

Другие варианты: Cloudflare Pages (Upload assets), GitHub Pages.

Свой домен (например `webnet-design.ru`): купите у регистратора и подключите в настройках Netlify, раздел Domains. Netlify подскажет, какие записи добавить у регистратора.

## Яндекс Метрика (2 минуты)

1. Создайте счётчик на https://metrika.yandex.ru (кнопка «Добавить счётчик», адрес сайта: ваш домен).
2. Скопируйте **номер счётчика** (цифры).
3. Откройте файл `assets/metrika.js`, найдите строку `var COUNTER_ID = 0;` и впишите номер вместо нуля. Сохраните.
4. Загрузите сайт заново на хостинг.

Счётчик считает посетителей на главной и на всех страницах работ. Кнопки «Написать в Telegram» и переходы в работы отмечаются как цели `telegram` и `open_work`. Чтобы видеть их в отчётах, создайте в Метрике две цели типа «JavaScript-событие» с этими идентификаторами.

## Что поменять под себя

Открывайте файлы в любом редакторе (Блокнот, VS Code). Используйте поиск и замену (Ctrl+H).

| Что | Где | Как |
|---|---|---|
| Ссылка на Telegram | `index.html`, `works/*.html`, `assets/want.js`: `https://t.me/x8844x` | Заменить на свою везде |
| Цены и сроки | `index.html`, блоки «Услуги» и «Тарифы» | Поменять числа |
| Тексты | `index.html` | Найти фразу и переписать |
| Логотип | Шапка в `index.html`, значок во вкладке (favicon) | Скажите Claude номер варианта, он установит |

- Бритва №3, Зерно и Ритм: **концепты** с вымышленными брендами. Kittys Zone: независимая работа для реально существующего салона в Дубае (внешняя ссылка), не официальный сайт компании. Это честно подписано на карточках и на самих страницах.

- Формы и записи в работах демонстрационные, данные никуда не отправляются.
